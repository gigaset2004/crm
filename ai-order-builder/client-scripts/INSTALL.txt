ADDRESS POLICY
SO Billing_* fields = Accounts.Billing_* fields.
SO Shipping_* fields = Accounts.Shipping_* fields.
No fallback from Contacts at all; empty Account fields clear Contact values.
Save is blocked if Account is not selected or its data is not available.
This applies when creating or editing a Sales Order in the native CRM form.

SUPPLIER POLICY
Every row is verified after Fill Sales Order for:
Product ID, Offer Product Name, Quantity, Unit Price, Supplier lookup ID.
If the first-row Supplier was dropped, it is written again and checked.
A failed supplier verification produces a clear error, not success.

US PRICE FORMAT
Widget unit-price column is a text input (avoids locale conversion to
comma decimal). Enter 27.15 or 10000.00. Commas (27,15 or 10,000) are
invalid and block Fill Sales Order. No automatic comma conversion.

   Fill Sales Order. Verify all 3 Supplier lookups before saving.
2. Enter 27.15 -> 27.15 displayed; enter 10,000 -> invalid.
3. Select Account A, then a Contact having a different address.
   The SO Billing/Shipping fields must match Account A only.
4. Save and reopen the SO to confirm the persisted address.
